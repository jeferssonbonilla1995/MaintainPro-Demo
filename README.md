## 🎯 ¿Qué es MaintainPro?

**MaintainPro** es un sistema de gestión de mantenimiento industrial que permite:

- 🏭 Gestionar máquinas con **kardex histórico**
- 🧩 Descomponer máquinas en **componentes recursivos** (componentes dentro de componentes)
- ⚠️ Registrar **fallas** con historial por máquina/componente
- 📅 Programar **mantenimiento preventivo** con planes automáticos
- 🛒 Controlar **stock de componentes** y generar órdenes de compra



## 🗂️ Componentes Recursivos (Funcionalidad Clave)

**No es solo una lista plana de componentes. Es una estructura JERÁRQUICA.**

**Cada componente** (en cualquier nivel) tiene:
- Imágenes
- Manuales/documentos
- Historial de fallas
- Historial de mantenimiento
- Stock de repuestos asociados

---

## 📋 Módulos del Sistema

| Módulo | Funcionalidades |
|--------|-----------------|
| 🏭 **Máquinas** | Registro de equipos / Imágenes / Manuales / **Kardex histórico** / Códigos QR |
| 🧩 **Componentes** | **Estructura recursiva** / Imágenes por componente / Documentos técnicos / Stock de repuestos |
| ⚠️ **Fallas** | Registro de fallas / Historial por máquina / Historial por componente / Soluciones registradas / Tiempo de inactividad |
| 📅 **Mantenimiento Preventivo** | Planes personalizados / Programación por tiempo o uso / Alertas automáticas / Tareas asociadas / Historial de ejecución |
| 🛒 **Compras** | Control de stock / Alertas de stock mínimo / Órdenes de compra / Historial de compras / Proveedores |

---

## 📊 Indicadores Clave

| Indicador | Qué mide |
|-----------|----------|
| **MTBF** | Tiempo medio entre fallas (por máquina y componente) |
| **MTTR** | Tiempo medio de reparación |
| **Disponibilidad** | % de tiempo que la máquina está operativa |
| **Costo de mantenimiento** | Por máquina, componente y período |
| **Cumplimiento preventivo** | % de preventivos realizados vs planificados |

---

## 🔔 Sistema de Alertas

| Tipo de alerta | Disparador |
|----------------|------------|
| Mantenimiento programado | Fecha/horas alcanzadas |
| Stock bajo de repuesto | Inventario por debajo del mínimo |
| Garantía por vencer | Fecha próxima |
| Orden de compra pendiente | Tiempo excedido |
